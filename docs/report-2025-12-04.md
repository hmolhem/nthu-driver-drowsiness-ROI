### 3. Analysis & Observations
- **Overfitting**: The massive gap between Train (94%) and Val (60%) indicates severe overfitting, even with the ROI approach.
- **Feature Mismatch**: The pre-trained ImageNet features (trained on dogs, cats, cars) are likely insufficient for distinguishing "drowsy eye" vs "alert eye" without fine-tuning. The frozen backbone extracts generic edges/shapes, but the classifier head is forced to memorize the specific training subjects to minimize loss.
- **Instability**: The validation metrics are highly volatile, suggesting the model hasn't found a robust minima.

### 4. Recommendation
**Unfreeze the Backbone.**

The current strategy of using a frozen backbone is limiting the model's ability to learn domain-specific features (e.g., eyelid closure, yawning mouth shape).
- **Action**: Modify `configs/roi_training.yaml` to set `freeze_backbone: false`.
**Hypothesis**: Allowing the backbones to update will enable the model to learn features that generalize better to unseen subjects.

### 5. Experiment: Fine-Tuning (Unfrozen Backbone)
We initiated a fine-tuning run with the following changes:
- **Backbone**: Unfrozen (Trainable)
- **Learning Rate**: Reduced to `0.0001` (from `0.001`) to preserve pre-trained knowledge.

**Initial Results (Epoch 1)**:
- **Train Accuracy**: **92.64%** (Maintained high accuracy)
- **Val Accuracy**: **55.84%**
- **Val Macro-F1**: **0.5010**
- **Observation**: The model starts with a strong bias towards "not drowsy" (Recall: 90%) and poor detection of "drowsy" (Recall: 21%). This is expected as the feature extractors adjust. We expect the "drowsy" recall to improve as training progresses.

### 6. Next Steps & Recommendations
1.  **Continue Fine-Tuning**: The current run is critical. We need to let the model train for at least 10-15 epochs to see if the "drowsy" recall improves as the backbone adapts.
2.  **Monitor Loss**: If validation loss continues to decrease (currently 0.85), it's a good sign. If it spikes, we may need to lower the learning rate further (e.g., to `1e-5`).
3.  **Evaluate**: After 30 epochs, we will evaluate the model on the test set to see if the ROI approach has successfully mitigated the subject-overfitting issue.
